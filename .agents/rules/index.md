# Правила backend

Файлы в этом каталоге — обязательные правила. Индекс только направляет к нужному файлу и не заменяет его содержимое.

Применяй файл, если задача затрагивает его область:

- `architecture/module-boundaries.md` — модули, compile-зависимости, владение БД, межсервисное взаимодействие, Kafka, outbox.
- `architecture/contracts.md` — REST API, DTO, ответы и ошибки, Kafka-топики, payload, заголовки, consumer'ы, сериализация.
- `development/conventions.md` — изменения кода, конфигурации, POM, миграций; работа с незакоммиченными изменениями.
- `testing/test-style.md` — стиль `*Test.kt` и генераторов данных: FreeSpec, Arb/Exhaustive, моки, очистка состояния.
- `testing/verification.md` — выбор тестов и команд проверки, изменения тестовой инфраструктуры.

Правила применения:

- Читай только файлы, релевантные текущей задаче. Не читай все правила заранее.
- Перед изменениями изучи применимые файлы.
- Если сомневаешься, применим ли файл, прочитай его. Не угадывай содержание.
- Требования отдельной функции ищи в задаче или спецификации, а не выводи из этих правил.

Справочные сведения о проекте — `.agents/context/backend.md`. Это не обязательные правила; читай их только при необходимости обзора.
