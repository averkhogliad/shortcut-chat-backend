# Архитектура

Маршрутизатор по архитектурным правилам backend. Файлы решают разные задачи и не заменяют друг друга.

- `module-boundaries.md` — читай при изменении состава модулей, compile-зависимостей, владения БД, межсервисного взаимодействия, Kafka или outbox.
- `contracts.md` — читай при изменении REST API, DTO, ответов и ошибок, Kafka-топиков, payload, заголовков, consumer'ов или сериализации.

Требования отдельной функции ищи в задаче или спецификации, а не выводи из этих правил.
